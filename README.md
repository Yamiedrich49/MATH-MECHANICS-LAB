# MATH MECHANICS LAB

数学ゲームの新しい仕組みを比較・検証するための試遊研究所です。  
**「考えて面白い、触って気持ちいい」** を目標に、少数の良問でゲームの核心を検証します。

## 収録ゲーム（初回・13問）

| ゲーム | ステージ | 研究テーマ |
| --- | ---: | --- |
| SCAN GRID | 4問 | 限られたスキャンから隠れた図形を見抜く・情報獲得 |
| CUT CIRCUIT | 4問 | 赤い灯りを消し、青い灯りを守る・グラフの切断 |
| TRIAD SHIFT | 5問 | 連続する3枚を循環して並び替える・置換と偶奇性 |

ブラウザで `index.html` を開けば遊べます。単一HTMLにCSSとJavaScriptを含めているので、インストールやビルドは不要です。

## 公開方法（GitHub Pages）

1. このリポジトリの **Settings → Pages** を開きます。
2. **Build and deployment → Source** を **Deploy from a branch** に設定します。
3. **Branch** を `main`、フォルダを `/(root)` にして **Save** します。
4. 公開が完了すると、以下のURLから遊べます。

https://yamiedrich49.github.io/MATH-MECHANICS-LAB/

## 開発方針

- iPhone Safari の縦画面を第一に考える
- 数学的な仮説を立てて操作する体験を重視する
- 効果音や演出で、ゲーム性の不足をごまかさない
- 7歳でも遊び始められ、大人にも奥行きがあることを目指す
- 500問への拡張は、少数の問題で面白さを確認してから判断する
