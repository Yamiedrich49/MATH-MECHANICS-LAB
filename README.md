## UI v5 / 2026-11-08 — First gesture onboarding

「初めて開いても何をするゲームか分からない」という試遊フィードバックを受け、**説明文を追加するのではなく、最初に触る体験から再設計**。

- **RIBBON REWIRE**：初級1問目に盤面内のドラッグ誘導を追加。端をつかんだ瞬間に接続可能箇所を示し、つなぎ替え後の変化をアニメーションで伝える。残りの問題には答えを先出ししない。
- **CHECKSUM**：故障が見える1問を導入し、まず直す操作を体験。続いて故障を隠し、行・列センサーと斜め検査から推理するステージへ自然に移行。
- Playwright + Chromiumによる操作試験：RIBBON全6問・CHECKSUM導入含む全7問をクリア。320px幅で横はみ出しなし、JavaScriptの実行時エラーなし。
- **未検証**：iPhone Safari実機の指の感触、音質、7歳児の初見操作、面白さの実プレイ評価。これらは完成判定の前に確認する。

## NEW RESEARCH / 2026-11-08

新しい数学ゲーム候補2作品を**既存の3作品とは独立した試遊ページ**として追加。ゲーム性を評価するため、少数の入門・上級問題を先に実装。

| 作品 | プレイ | 実装内容 | 検証 |
| --- | --- | --- | --- |
| RIBBON REWIRE | [遊ぶ](https://yamiedrich49.github.io/MATH-MECHANICS-LAB/research/ribbon-rewire.html) | 紐の両端を隣接ノードにつなぎ直し、目標の両端位置に到達する。3×3～4×4、6問 | 各問題の最短解の存在・最短手数・一意性を全探索。全6問をブラウザのドラッグ操作でクリア |
| CHECKSUM | [遊ぶ](https://yamiedrich49.github.io/MATH-MECHANICS-LAB/research/checksum.html) | 行・列の故障数の偶奇を読み、斜め検査を選んで故障マスを修復する。4×4、6問 | 故障パターン全列挙。各問題は定めた検査回数以内に一意特定可能。全6問をブラウザ操作でクリア |

どちらも単一HTMLで動作。390px幅・320px幅のChromiumで描画と主要操作を確認済み。RIBBON REWIREはつなぎ替え時の局所的な接続アニメーションを強化。CHECKSUMは行・列のセンサーを触れるようにし、対応する行・列と交点を盤面内で直接強調。390px×844pxでは初級問題の操作部を1画面に収めた。iPhone Safari実機での操作感、音、7歳の子どもによる試遊は未検証。

### 試遊で重点的に評価したいこと

- RIBBON REWIRE：つなぎ替えた結果を予測できるか、深い先読みが必要になるか、それとも端を適当に動かすだけになるか。
- CHECKSUM：故障箇所を自分で発見している実感があるか、斜め検査を選ぶ判断が楽しいか、それとも計算教材に感じるか。

## UI Build v4 — 2026-11-07

| ゲーム | 問題数 | 今回の改善 |
| --- | ---: | --- |
| SCAN GRID | 4 | スキャンと回答を**同じ1枚の盤面**で実行。候補の自動可視化を廃止し、指でマスを塗る |
| CUT CIRCUIT | 6（上級2＋旧初級4） | 数学的に全探索検証した最小切断問題（4本・5本）を先頭へ。線を横切るスワイプで切断 |
| TRIAD SHIFT | 5 | 「押した後」の答えプレビューを撤去。数字の下に対応した回転矢印を置き、約0.5秒の移動アニメーションを追加 |

### 研究上の位置づけ

この更新は**ゲーム性を評価できる状態を目指したUI・問題設計の試作**です。完成版や「面白さが証明されたゲーム」ではありません。

- SCAN GRID：行・列を調べた後、同じグリッドをドラッグで塗り、「この形で答える」
- CUT CIRCUIT：赤の電源経路だけを遮断し青の経路を残す。最初の2問は全探索で最少切断本数と一意解を確認
- TRIAD SHIFT：隣り合う3枚だけの右循環を矢印で指示し、実際の移動を目で理解する。最初の5問の最短手数は 1, 2, 4, 6, 7

Chromium（390px幅）で、SCAN GRIDの同一盤面への描画、CUT CIRCUITの上級2問のスワイプクリア、TRIAD SHIFTのアニメーション付きクリアを自動操作で検証。iPhone Safari実機と実プレイヤーの感想は未検証です。

旧版のファイルはこのリポジトリのコミット履歴から確認できます。
