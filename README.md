## TIDE / UI refinement — 2026-11-09

フィードバック：「色の広がり方のルールが曖昧」。

- **確定ルール**：選んだ色の領域を構成する全マスから、上下左右の空きマスに対し、同時に1マスぶんだけ拡張。斜め移動・他色の上書き・他色を飛び越すことはできない。
- **初回のみ**：ステージ1の次に色づく4マスを薄い色で示し、指で触れたときの変化と一致させる。ステージ2以降は新たに色づく場所を事前に表示しない（予測の楽しさを守る）。
- **操作反応**：押した色の領域全体が同時に反応。拡張時の新規マスのアニメーションを同時化し、何段階も連鎖するように見える時間差を廃止。
- **検証**：390px・320px幅でレイアウト確認。全8問を画面のタップ操作で再クリア、JavaScript例外なし。ゲームロジック・問題データ・進捗保存キーは変更なし。iPhone Safari実機の評価は未検証。

## NEW PLAYABLE RESEARCH — TIDE / 2026-11-08

**[TIDEをプレイ](https://yamiedrich49.github.io/MATH-MECHANICS-LAB/research/tide.html)**

直感的な「触ると、色の領域が隣の空きマスへ一斉に1歩成長する」操作を核とする領域競争パズル。各色の領域を対応する色のゴールまで到達させる。領域は相互に侵食できないため、タップする順番に意味がある。

- **8ステージ**：3×3・1色・1手の導入から、4×4・3色・8手の先読み問題まで
- **数学的検証**：各問題をBFSで全探索し、各ステージに最短解が存在し、最短操作列が1通りであることを確認。以前の4×4・3色・最短6手の提案例も再検証して収録
- **操作**：色のかたまりのどこをタップしても1歩成長。別色にゴールを奪われる／手数切れの場合は1手戻してやり直せる。ゴールは色とA/B/Cで識別できる
- **演出**：段階的に広がる領域、短い操作音・成功和音、設定で消音、進捗保存
- **検証**：Chromiumで全8問の正解操作、画面幅320/390/430px、実際のタップ・誤手・Undo・次問遷移をテスト。JavaScript実行時エラー・横はみ出しなし
- **未検証**：iPhone Safari実機での表示・指の感触・音質、初見プレイヤーの理解度とゲームとしての面白さ。**研究試作であり採用確定ではない**

### 研究上の位置づけ

この更新は**ゲーム性を評価できる状態を目指したUI・問題設計の試作**です。完成版や「面白さが証明されたゲーム」ではありません。

- SCAN GRID：行・列を調べた後、同じグリッドをドラッグで塗り、「この形で答える」
- CUT CIRCUIT：赤の電源経路だけを遮断し青の経路を残す。最初の2問は全探索で最少切断本数と一意解を確認
- TRIAD SHIFT：隣り合う3枚だけの右循環を矢印で指示し、実際の移動を目で理解する。最初の5問の最短手数は 1, 2, 4, 6, 7

Chromium（390px幅）で、SCAN GRIDの同一盤面への描画、CUT CIRCUITの上級2問のスワイプクリア、TRIAD SHIFTのアニメーション付きクリアを自動操作で検証。iPhone Safari実機と実プレイヤーの感想は未検証です。
