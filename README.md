# MATH MECHANICS LAB

**「考えて面白い、触って気持ちいい」** 数学パズルのメカニクスを比較する研究所。

遊ぶ： https://yamiedrich49.github.io/MATH-MECHANICS-LAB/

## 試遊できる3ゲーム（合計13ステージ）

| ゲーム | ステージ | やること |
| --- | ---: | --- |
| SCAN GRID | 4 | 行・列をスキャンして、隠れた形を特定する |
| CUT CIRCUIT | 4 | 電線を切り、赤を消して青を守る |
| TRIAD SHIFT | 5 | 3枚ずつ回して数字を順番に並べる |

## UI Build 02 — 2026-11-07

初期版は、ゲームの目的と操作が分かりにくく、面白さを判断する前に迷ってしまう問題があったため全面改修。

- **ゲーム選択画面**：3作品の目的と操作をイラスト付きで表示
- **導入設計**：各ステージの目標を日本語で明示。最初に触る場所を案内
- **SCAN GRID**：隠された形の見本、候補数、使用可能スキャン、候補の絞り込み結果を可視化
- **CUT CIRCUIT**：赤は消灯、青は点灯という達成条件、線の切断・再接続、残り切断数を可視化
- **TRIAD SHIFT**：現状の並び、目標の並び、3枚回転ボタン、1手もどすを視覚的に分離
- **演出**：音ON/OFF、操作音、成功時の短い和音、クリア後の次のステージ導線
- **スマートフォン**：iPhone縦画面を重視し、狭い320px画面でも横スクロールを抑制
- **進捗**：従来と同じローカル保存キー `math_mechanics_lab_20261107` を維持

全13ステージについて、ブラウザ自動操作でクリアを確認。iPhone Safari実機での操作・音の聴感評価、7歳の子どもによるプレイテストはこれからです。

## GitHub Pages 設定

[Settings → Pages](https://github.com/Yamiedrich49/MATH-MECHANICS-LAB/settings/pages) を開き、`Deploy from a branch` → `main` → `/(root)` を選びます。

単一の `index.html` で動作し、外部ライブラリやビルド環境は不要です。
